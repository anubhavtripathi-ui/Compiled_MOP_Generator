# 📄 MOP Generator

Automated Method of Procedure (MOP) document generator.

## What it does
- Upload your input MOP file (.docx, .pdf, .txt)
- Enter Activity Name and Vendor Name
- Get a structured, formatted MOP Word document instantly
- Zero data storage — everything processed in memory

## How to use
Visit the app link and follow the on-screen instructions.

## Supported Input Formats
- Word Document (.docx, .doc)
- PDF (.pdf)
- Text File (.txt)

## Output
- `ActivityName_VendorName_MOP.docx` — Formatted MOP
- `SOP_ActivityName.[ext]` — Your input file copy (for SOP section)
